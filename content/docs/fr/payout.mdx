## Authentification

![Illustration Authentification](https://sc-digital.nyc3.cdn.digitaloceanspaces.com/sc-digital/images/1753185228523-api_key_docs.png)

Avant de faire une requête de retrait, vous devez (Allez dans la section **Paramètre**) :

1. **Générer une clé API** depuis votre tableau de bord Money Fusion.
2. **Ajouter l'adresse IP de votre serveur** (qui initie la requête) dans votre dashboard.
<Callout type="warning" title="Adresse IP fixe requise">    
    Si votre hébergeur ne vous fournit pas d’adresse IP fixe et que votre adresse IP est susceptible de changer, vous devez contacter votre hébergeur afin de vérifier les options disponibles.
    
    Dans la plupart des cas, une **offre Premium/Pro** peut être nécessaire pour bénéficier d’une adresse IP fixe ou dédiée. Certains hébergeurs gratuits ou certaines offres d’entrée de gamme ne proposent pas cette fonctionnalité.
    
    Cela peut notamment concerner des services tels que **Vercel, Cloudflare**, les hébergements mutualisés ou les offres gratuites.
    
    Si votre hébergeur ne permet pas d’obtenir une IP fixe, nous vous recommandons d’utiliser un **serveur dédié ou un VPS dont vous contrôlez l’adresse IP**.
</Callout>
3. Inclure cette clé API dans l’en-tête des requêtes HTTP :

```md
moneyfusion-private-key: VOTRE_CLE_API
Content-Type: application/json
```

## Endpoint de retrait

**POST** `https://pay.moneyfusion.net/api/v1/withdraw`

### Corps de la requête (JSON)

```json
{
  "countryCode": "ci",
  "phone": "05xxxxxxxxx", // MTN
  "amount": 200,
  "withdraw_mode": "mtn-ci",
  "webhook_url": "https://votre-serveur.com/api/withdraw/callback"
}
```

### Réponse en cas de succès

```json
{
  "tokenPay": "D0h6fjyjkCfi",
  "statut": true,
  "message": "Retrait soumis avec succès"
}
```

### Réponse en cas d’erreur

```json
{
  "statut": false,
  "message": "Tous les champs (countryCode, phone, amount, withdraw_mode) sont requis."
}
```

### 🔐 À propos du `tokenPay`

Le champ `tokenPay` est un identifiant unique généré lors de l’initiation d’un retrait.  
Il permet de suivre et vérifier la transaction. Ce token doit être conservé côté client ou serveur car il sera réutilisé pour :

- Valider et identifier la transaction dans les notifications envoyées par webhook ou les responses de l'IPN.
- Faire le lien entre la demande initiale et son statut final.

Ce token garantit ainsi la traçabilité et la sécurité du processus de retrait.

---

### Paramètres requis ou Non (JSON body)

| Champ           | Type     | Obligatoire | Description                                            |
| --------------- | -------- | ----------- | ------------------------------------------------------ |
| `countryCode`   | `string` | ✅          | Code du pays (ex: `ci` pour Côte d’Ivoire)             |
| `phone`         | `string` | ✅          | Numéro à retirer                                       |
| `amount`        | `number` | ✅          | Montant à retirer                                      |
| `withdraw_mode` | `string` | ✅          | Méthode de retrait                                     |
| `webhook_url`   | `string` | NON         | URL vers laquelle Money Fusion enverra la notification |

## Méthodes de retrait prises en charge (`withdraw_mode`)

Les valeurs disponibles pour `withdraw_mode` et `countryCode` sont retournées dynamiquement via :

```http
GET https://pay.moneyfusion.net/api/v1/withdraw/methods
```

**Exemple de réponse :**

```json
{
  "success": true,
  "data": [
    {
      "country": "Côte d'Ivoire",
      "code": "ci",
      "currency": "XOF",
      "paymentMethods": [
        { "key": "mtn-ci", "name": "MTN" },
        { "key": "orange-money-ci", "name": "Orange" },
        { "key": "moov-ci", "name": "Moov" },
        { "key": "wave-ci", "name": "Wave" }
      ]
    }
  ]
}
```

- `code` → valeur à utiliser pour `countryCode`
- `paymentMethods[].key` → valeur à utiliser pour `withdraw_mode`

## Notification Instantanée de Paiement (`IPN`)

### Vérification de l'état des retraits

**GET** `https://pay.moneyfusion.net/api/v1/payout/check-status/${token}`


### Exemple de Réponses

#### En cas de Success

```json
{
  "success": true,
  "data": {
    "tokenPay": "6a983c2c23a361c193fc21d4",
    "status": "success",
    "phone": "0700101213",
    "method": "mtn-ci",
    "amount": 226,
    "createdAt": "2026-09-02T15:09:32.847Z",
  }
}
```

#### En cas d'échec

```json
{
  "success": true,
  "data": {
    "tokenPay": "6a9962270f45c742241eac01",
    "status": "failed",
    "phone": "0700101213",
    "method": "mtn-ci",
    "amount": 205,
    "createdAt": "2026-09-03T12:03:51.685Z",
  }
}
```
#### Mauvais token

```json
{
  "success": false,
  "message": "Withdrawal not found"
}
```


### Types de statut du retrait

|  Status     |  Description                            |
|-------------|-----------------------------------------|
|  `pending`  |  Le retrait est en cours de traitement  |
|  `success`  |  Le retrait a été effectué avec succès  |
|  `failed`   |  Le retrait a échoué ou a été annulé    |

### Champs de données de la réponse d'état

| Champ           | Type                  | Description                      |
| --------------- | --------------------- | -------------------------------- |
| `status`        | Chaîne de caractères  | État des retraits                |
| `tokenPay`      | Chaîne de caractères  | token de Retrait                 |
| `phone`         | Chaîne de caractères  | Numéro de téléphone du retrait   |
| `method`        | Chaîne de caractères  | Mode de paiement                 |
| `amount`        | Nombre                | Montant de la transaction        |
| `createdAt`     | Chaîne de caractères  | Date de d'initiation du retrait  |

## Webhooks

Votre serveur doit **écouter les événements suivants** via l’URL `webhook_url` fournie :

```js
-payout.session.completed;
-payout.session.cancelled;
```

### Exemple de payload webhook :

```json
{
  "event": "payout.session.cancelled",
  "tokenPay": "D0h6fjyjkCfi",
  "montant": 205,
  "numeroRetrait": "07xxxxxxxxx",
  "moyen": "orange-money-ci",
  "webhook_url": "https://votre-serveur.com/api/withdraw/callback",
  "createdAt": "2025-07-17T17:35:23.468Z"
}
```

### Événements possibles

| Événement                  | Description                           |
| -------------------------- | ------------------------------------- |
| `payout.session.completed` | Le retrait a été effectué avec succès |
| `payout.session.cancelled` | Le retrait a échoué ou a été annulé   |

---

## Exemple de code (Node.js / Express)

```js
// Endpoint Webhook
app.post("/api/withdraw/callback", (req, res) => {
  const { event, tokenPay, montant, numeroRetrait, moyen, createdAt } =
    req.body;

  if (event === "payout.session.completed") {
    // Marquez le retrait comme réussi dans votre DB
  } else if (event === "payout.session.cancelled") {
    // Mettez à jour le retrait comme échoué
  }
});
```
